Why this shape

Provider-clean. Dormant until you say go.

Each concern is an isolated module, so a project can deepen or drop any one without disturbing the others.

→

Boots with no key

The whole app runs the moment you clone it. Agent endpoints return 503 until you set ANTHROPIC_API_KEY — the base template never breaks.

→

Two ways to run the agent

/chat drives the single tool-using loop; /orchestrate routes through the supervisor to a worker. Pass a conversation_id to continue, omit it to start.

→

Swap the brain in one file

Provider setup is only in client.py; orchestrator.py is the swap point for LangGraph or the Microsoft Agent Framework.

→

PRs review themselves

Every pull request gets an automatic Claude code-quality review via GitHub Actions.

.env
# the agent stays dormant until this is set
ANTHROPIC_API_KEY=sk-ant-...
LLM_MODEL=claude-opus-4-8
TRACING_ENABLED=true   # logs; Sentry if SENTRY_DSN
# LANGCHAIN_TRACING_V2=   # optional LangSmith/OTel
agents/tools.py — add a capability
# register once; the loop & orchestrator discover it
TOOLS["get_weather"] = (schema, handler)

# assign it to a worker by name in orchestrator.py
WORKERS["research"].tools += ["get_weather"]
The interface

Three endpoints, mounted and waiting.

All under /api/v1/agents. Turns persist to the Conversation tables; the response returns the new id when you start one.

GET /agents/health → { "configured": bool }
POST /agents/chat → { "reply", "conversation_id" } · auth
POST /agents/orchestrate → { "reply", "conversation_id", "worker" } · auth

Get started

Generate a project in one command.

Fork it, clone it, or generate with Copier — it copies every file, asks your config questions, and fills the .env.

$copier copy gh:Robertjam954/agentic-ai-app-template my-agent-app --trust
$git clone https://github.com/Robertjam954/agentic-ai-app-template.git
$docker compose up -d && open http://localhost/agent

The app boots and the dashboard works immediately. Set ANTHROPIC_API_KEY in .env to wake the agent — until then the agent routes answer 503 and everything else runs normally.
